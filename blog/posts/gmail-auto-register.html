Gmail自動連携スクリプトで売上を自動記録する方法

複数プラットフォームでせどりをしていると、メルカリ・ヤフオク・ラクマ・ヤフーフリマそれぞれから 売上通知メールが届き、手動でスプレッドシートに入力するのは大変です。 今回紹介するGoogle Apps Script（GAS）を使えば、1分ごとに自動でメールを読み取り、在庫管理表に転記できます。

仕組みの概要

GASはGoogleのサーバー上で動くJavaScriptです。Gmailにアクセスする権限を付与すると、 受信トレイを定期的にスキャンして売上通知を検出し、スプレッドシートへ書き込めます。

  • 対応プラットフォーム：メルカリ・メルカリShops・ヤフオク・ヤフーフリマ・ラクマ
  • 重複登録防止：最終チェック時刻をScriptPropertiesに保存
  • 同時実行防止：LockServiceで排他制御

スクリプトの導入手順

  1. Googleスプレッドシートを新規作成し、シート名を「帳上管理」にする
  2. メニューから「拡張機能」→「Apps Script」を開く
  3. 下記のコードをコピー＆ペーストして保存する
  4. 初回実行時にGmailへのアクセス権限を承認する
  5. トリガーで「checkSalesEmails」を1分ごとに実行するよう設定する

メインエントリー関数

const SHEET_NAME    = '帳上管理';
const STATUS_COL_NUM = 14; // N列（ステータス）

function checkSalesEmails() {
  const lock = LockService.getScriptLock();
  if (!lock.tryLock(0)) {
    Logger.log('別の実行が進行中のためスキップ');
    return;
  }
  try {
    const sheet = getOrCreateSheet();
    const props = PropertiesService.getScriptProperties();
    const lastCheck = props.getProperty('lastCheck');
    const since = lastCheck
      ? new Date(new Date(lastCheck).getTime() - 3 * 60 * 1000)
      : new Date(Date.now() - 7 * 24 * 60 * 60 * 1000);

    processMercariEmails(sheet, since);
    processYahooAuctionEmails(sheet, since);
    processYahooFleaMarketEmails(sheet, since);
    processMercariShopsEmails(sheet, since);
    processRakumaEmails(sheet, since);

    props.setProperty('lastCheck', new Date().toISOString());
    Logger.log('チェック完了: ' + new Date().toLocaleString('ja-JP'));
  } finally {
    lock.releaseLock();
  }
}

運用のコツ

トリガーを1分間隔に設定すると月間の無料実行枠（6時間/日）を消費しやすいです。 売上が多くない場合は5〜10分間隔でも十分です。 また、スクリプトのエラー通知メールが届いた場合は、 Gmailのフィルタ変更（件名の文言変更）が原因であることが多いので確認してください。
